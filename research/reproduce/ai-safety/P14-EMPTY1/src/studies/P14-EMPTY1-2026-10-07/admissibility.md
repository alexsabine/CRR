# Admissibility report, P14-EMPTY1 (2026-10-07, before freeze)

- **Data.** Synthetic linear-Gaussian worlds generated by the frozen `generate.py` from declared seeds, *after* the freeze and the anchor. No natural dataset is opened. The target seeds (100000–100599) and control seeds (200000+, 300000+, 400000+) were never run before the freeze; the development check used seeds 900000–900039 only (`notebook/AGENT_LOG.md`, 2026-10-07).
- **Independent unit.** One world (one seed). Worlds share nothing but the family parameters; the score of one world does not depend on another.
- **Independent event / no encoded target.** The quantity scored is the filter's error and calibration against the true state, which the estimators never see. The evaluation set is defined from the observable channel (bit-identical repeats) so that no hidden flag selects the evaluation steps.
- **Rivals can win.** HOLD, GATED and FROZEN run the same Kalman recursion with the same correct (A, Q, H, R); only the handling of a repeat differs. In the frozen-world control EMPTY and FROZEN coincide exactly, so EMPTY cannot win there by construction, which is what the control requires.
- **Reduction.** EMPTY is the native missing-observation filter once a repeat is recognised. If the oracle filter (missingness flagged) were a registered rival the candidate could at best tie; the oracle is not a rival here because it uses information the channel does not provide. A tie against GATED or HOLD would be recorded as FAIL by the generic engine and read as a reduction.
- **Resolution.** Scores are means over at least 10 evaluation steps per world; worlds with fewer are excluded with the reason printed by the scorer.
- **Multiplicity.** One primary comparison (EMPTY against the strongest rival per world); two registered sensitivity cells (evaluation set stale-only and all-steps); three controls. No other comparison is scored.
- **Gate status.** OPEN: must-pass and must-fail controls are registered with the same statistic as the primary.
- **Ceiling.** PASS-0 at most (generic engine; one operator; synthetic worlds: rung R4 declared-synthetic). A pass establishes a restricted engineering effect for this plant class; it establishes nothing about A3 as ontology and nothing about corrigibility.
