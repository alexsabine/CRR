# Independent-engagement log (Session 6 audit, extended through Session 8)

This file logs external references to or engagement with CRR claims
located via search or supplied by collaborators. Each entry is
classified per `CAMPAIGN.md` PART III honesty discipline:

- **Sympathetic engagement** (S): citation, discussion,
  paraphrase, but not by an unaffiliated group, OR not replicating
  a CRR prediction.
- **Independent confirmation** (I): unaffiliated group, separate
  data, replicating a specific CRR prediction. **Only this
  promotes a claim to T4.**
- **Independent structural-adjacency** (I-SA): unaffiliated group,
  peer-reviewed, deriving structures *parallel* to CRR but not
  testing CRR's specific predictions.
- **Sympathetic but independent** (S/I): potentially independent
  but engagement does not yet replicate a specific prediction.
- **Pending verification**: reference supplied but cannot be
  verified in the campaign sandbox.

## ★ Mazoyer et al. 2014 — Hemispheric language lateralization (Gaussian mixture)

- **Citation:** Mazoyer, B. et al. (2014). *PLoS ONE* 9(6): e101165.
- **Source:** cited in `Sabine_Hemispheric_Asymmetry...pdf` as
  empirical test data.
- **Status: INDEPENDENT empirical data, used by Sabine to test
  CRR prediction.**
- **The test (per Sabine 2026):**
  - Mazoyer 2014 provides 3-Gaussian mixture decomposition of
    HFLI (n=144 right-handers) with publicly-available SDs:
    G1 (typical-strong): mean=65.3, SD=8.0, CV = 12.25%
    G2 (typical-moderate): mean=43.9, SD=5.3, CV = 12.07%
    G3 (ambilateral): mean=4.4, SD=17.7
  - **CRR prediction:** CV = 1/(2π) ≈ 15.92% (Z₂-rupture).

    prediction.**

    identical CV (12.25% vs 12.07%) despite different means and
    SDs — *consistent with CRR's topological-invariance claim*
    that CV is structural rather than parametric.
  - **Sabine's own honest assessment:** "the framework has not
    been confirmed... a deviation of approximately 23% from the
    prediction... a genuine discrepancy that requires diagnosis
    rather than dismissal."
- **Three diagnostic candidates (per Sabine):**
  1. Class B regulation: callosal inhibition compresses effective
     Ω from 1/π to ~0.244. Predicts split-brain patients should
     show CV closer to 15.9%.
  2. σ(C*) refinement: if equipartition assumption σ(C*) = 1/2
     is replaced by σ(C*) ≈ 0.385, fits data exactly.
  3. Geodesic-extent overshoot: π → π+0.7 gives CV ≈ 13.0%.
- **Impact on campaign:**
  - This is a **published empirical-data test of a CRR prediction**.
    Sabine ran it; the prediction overshot by 23%.
  - For B5 (EEG class ordering) and adjacent claims: this should
    be recorded as a **partial consistency** — structural
