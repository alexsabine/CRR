# P11: Kepler solar-type stellar rotation period CV equals 1/(4π)

## Canonical statement

Stellar rotation is a continuous SO(2) phase cycle. Per Convention C2/M22, CV = 1/(2 φ_G) = 1/(4π) ≈ 0.0796.

## Domain(s)

P, T

## Source in CRR canon

Pre-registered Session 7. Data target: McQuillan, Mazeh, Aigrain (2014) ApJS 211 24 — Kepler rotation periods for ~34,030 stars; restrict to solar-type (M_eff = 5500–6000 K).
