# Be4: Bee compound-eye visual relay count = 4 (per geometry-of-senses)

## Canonical statement

Per the geometry-of-the-senses paper, paired Z₂ apertures of ~2 mm separation predict ~4 SO(2) relay stages. Bee interocular ≈ 2.0 mm, so relay count should be exactly 4.

## Domain(s)

B

## Source

Pre-reg test against canonical bee neuroanatomy (Strausfeld 1976; Paulk et al. 2008).
