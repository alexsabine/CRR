# B15: Cortical pyramidal ISI CV in vivo (Class C noise-dominated)

## Canonical statement

In-vivo cortical pyramidal neurons in awake-behaving preparations show near-Poisson firing (CV_ISI ≈ 1.0). Predicted Class C (noise-dominated): CV > 1/(2π).
