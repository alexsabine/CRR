# Be2: Honeycomb wall-thickness CV equals 1/(2π)

## Canonical statement

Wax-wall completion is a Z₂ rupture (wall closes when accumulated wax mass crosses threshold) on the SO(2) regulator of the 6-fold local angular constraint. CRR predicts Class A Z₂-rupture-with-SO(2) CV = 1/(2π).

## Domain(s)

B, T

## Source

Pre-reg test on published honeycomb wall-thickness measurements (Hepburn, Pirk; Bauer, Bienefeld).
