# Be1: Waggle-dance angular heading SD/180° equals 1/(4π)

## Canonical statement

Bee waggle-dance is a pure SO(2) phase observable (direction encoded by waggle angle relative to gravity). CRR predicts Class A SO(2) angular CV = 1/(4π) ≈ 0.0796 across fast-returning foragers.

## Domain(s)

B, T

## Source

Pre-reg test on published waggle-dance angular-precision studies (von Frisch baseline; Tanner/Visscher; Couvillon).
