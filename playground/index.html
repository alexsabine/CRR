The playground

CRR began as play: simulations and songs for feeling how change, memory and reorganisation work before meeting any equations. Everything here is an illustration, not a test.

Many of these toys were built with earlier forms of CRR (a cut at C·Ω = 1 and an exp(C/Ω) memory kernel). The current form is on CRR Explained; the tested work is under Research. Desktop browsers recommended.
