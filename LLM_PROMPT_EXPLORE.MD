CRR is a TEMPORAL GRAMMAR: it provides the structural rules

The three core equations:
1. Coherence: C(x,t) = ∫L(x,τ)dτ
   Accumulation of lived significance over time.
   (The PAST — inside the temporal blanket)
2. Rupture: δ(now)
   Scale-invariant Dirac delta marking the ontological present.
   (The NOW — the temporal blanket itself)
3. Regeneration: R = ∫φ(x,τ)exp(C(x,τ)/Ω)Θ(...)dτ
   Reconstruction weighted by exponential memory kernel.
   (The FUTURE — outside the temporal blanket)
   φ = reconstruction resource available at each past moment.
   exp(C/Ω) = memory weighting — moments of high coherence
   are exponentially amplified during reconstruction.
   Θ = Heaviside step function enforcing causality —
   reconstruction can only draw from the accessible past.
Key relationships:
- Ω = 1/φ (phase to rupture in radians)
- Ω = σ² (variance / boundary permeability)
- Precision = 1/Ω
- Small Ω → rigid system. exp(C/Ω) sharply peaked.
  Only highest-coherence memories accessible. System
  reconstitutes the same pattern. (Habit, trauma, addiction.)
- Large Ω → flexible system. exp(C/Ω) ≈ 1 for all history.
  Everything accessible. Transformation possible.
  (Insight, healing, phase transition.)
- Ω collapse → dangerous rigidity, approaching criticality.
Universal rupture condition: C · Ω = 1
Coherence × variance = 1 at every rupture point.
- Z₂ symmetry (bistable): Ω = 1/π, C = π → C·Ω = 1 ✓
- SO(2) symmetry (rotational): Ω = 1/2π, C = 2π → C·Ω = 1 ✓
Open question: is the fundamental condition C·Ω = 1
(product) or C = 1/Ω (equivalently C = Ω⁻¹)? Both give
the same numerical result but imply different geometric
readings — the product form suggests a complementarity
(like Heisenberg), while C = 1/Ω suggests coherence
simply reaches the inverse of the system's variance.
